# Arte Felino · Street Cat

Galería 3D de la colección de Street Cat (three.js + GSAP). Se publica con GitHub Pages en https://streetcatprrr.github.io/COLLECTION/ y se inserta en una página de streetcat.com.

- `index.html`: la galería completa, con el catálogo de obras incluido.
- `fonts/`: Cormorant Garamond (licencia SIL Open Font License).
- `media/`: versiones web de cada obra (cuadrícula y ficha). Los originales no están aquí.

Este repositorio no se edita a mano: se genera desde la carpeta `galeria-streetcat` del Mac de Street Cat con `_build/publicar.py`.
